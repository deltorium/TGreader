# Telegram Chat Top

Статический сайт для определения самых активных участников Telegram-чата по JSON-экспорту.

## Возможности

- загрузка `result.json` из экспорта Telegram;
- обработка полностью в браузере, без бэкенда;
- фильтр по начальной и конечной датам;
- исключение любых участников из рейтинга;
- выбор размера топа: 10 / 20 / 50 / 100 / все;
- экспорт готового рейтинга в CSV;
- адаптивная верстка для телефона и ПК.

## Как получить JSON из Telegram

В Telegram Desktop открой экспорт данных нужного чата и выбери формат **Machine-readable JSON**. После экспорта выбери файл `result.json` на сайте.

## Запуск локально

Обычный статический сервер подходит. Например:

```bash
python3 -m http.server 8080
```

Затем открой `http://localhost:8080`.

## GitHub Pages

1. Создай репозиторий на GitHub.
2. Положи `index.html`, `style.css` и `app.js` в корень репозитория.
3. В **Settings → Pages** выбери публикацию из ветки `main` и папки `/ (root)`.
4. GitHub Pages выдаст адрес сайта.

Сайт не требует Node.js, сборки или сервера.

## Как считается активность

В рейтинг попадают записи из `messages`, у которых `type === "message"`, есть автор и корректная дата. Каждое такое сообщение считается как 1 единица активности. Диапазон дат включительный: выбранные даты считаются целиком, от 00:00 до 23:59:59.

## Особенности Telegram JSON

Скрипт учитывает `text` как строку и как массив объектов с полем `text`. Для автора используются `from` и `from_id`; для некоторых анонимных записей дополнительно поддерживаются `actor` и `actor_id`.
